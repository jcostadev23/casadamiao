# Casa Damião

Website informativo sobre a **Casa Damião**, uma fundação dedicada ao acolhimento temporario de crianças.

## 🌟 Sobre o Projeto

Este website tem como objetivo apresentar a missão, valores e atividades da **Casa Damião**, dando visibilidade ao seu trabalho social. A plataforma fornece informações sobre:

- A história e propósito da Casa Damião
- As ações realizadas pela fundação
- Os patrocinadores e parceiros envolvidos
- Um link direto para uma aplicação externa onde os visitantes podem fazer doações

## 🧩 Funcionalidades

- Página informativa sobre a fundação
- Seção dedicada aos patrocinadores
- Redirecionamento para aplicação de doações
- Monitorização de visitas com Google Analytics

## 🛠 Tecnologias Utilizadas

- [Next.js](https://nextjs.org/) – Framework React para aplicações web modernas
- [React](https://reactjs.org/) – Biblioteca para construção da interface do utilizador
- [TypeScript](https://www.typescriptlang.org/) – Superset de JavaScript com tipagem estática
- [Google Analytics](https://analytics.google.com/) – Monitorização e análise de tráfego
